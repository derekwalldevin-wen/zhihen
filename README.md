# 纸痕 · 盲压浮雕工坊

一个把照片变成同色棉纸浅压印的轻量浏览器工具。作者：德里克文。版本：1.0，2026-10-09。

## 使用

只需要 `index.html`。CSS、JavaScript、Worker 与三张示例照片全部内嵌；无需构建、依赖、API Key 或登录。

在支持本地 HTML 与 Blob Worker 的现代浏览器里打开 `index.html`。若浏览器或系统禁止打开本地 HTML，可以在本目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/index.html`。这仅提供本机文件，无需互联网。手机浏览器支持窄屏触控；本地 HTML 的打开方式取决于系统，部分文件预览器不执行 JavaScript，应使用真正的浏览器。本版本没有 Service Worker，不保证在线网址离线刷新；离线使用请保留完整 HTML 或使用本地服务。

1. 选择或拖入 JPG / PNG，最大 25 MB、4800 万像素；也可使用内嵌样片。
2. 选择浅压凸或浅压凹，调整纸色、压痕深浅、细节简化、侧光方向、纸纹。
3. 默认保留原比例。3:4、1:1、4:3 是等比例居中裁切，不拉伸；首版不提供手动移动裁切框。
4. 两个画面使用相同取景，左边是原照片，右边是实时生成的纸面。
5. 默认导出无文字、无边框、无水印的完整结果 PNG。也可选上下对比，原图在上、结果在下，没有额外标题或分隔文字。

导出长边有 1600、2400、3200 px 三档；对比图的「长边」指每一张子图，因此最终画布高度为子图的两倍。压印深浅 0 可得到无压痕的纸面。恢复默认会恢复全部参数与导出设置，但保留当前照片。

## 画面与算法边界

它是**亮度风格化算法，不是 AI 场景理解，也不重建真实深度**。输出不保留照片颜色；主体和背景共用同一纸色，依靠微弱的明暗变化形成浅表起伏。

流程：按取景将原图绘制到目标画布 → 亮度近似高度（较暗区域较高）→ 三次可分离盒式平滑近似高斯柔化 → 沿指定方向计算高度梯度 → 有界、低对比漫反射明暗 → 固定种子的细纸纹。没有金属高光项、颜色叠加或外部模型。计算在本地 Blob Web Worker 内运行。

预览长边 800 px。导出从原图按目标像素重新取样、分析、计算光影与纸纹，**不放大预览截图**。平滑尺度随目标尺寸变化，因此预览与导出大形一致，但细节可能稍有差异。低分辨率原图不会凭空产生摄影细节。

清晰主体、简洁背景通常更好。原图的阴影、毛发、木纹和文字也会影响高度；复杂照片仍可能出现多余纹路，建议提高细节简化或降低压痕。首版没有分割或自动去背景，无法把所有照片转成轮廓干净的实体盲压模具。

## 隐私、离线与并发

没有统计、追踪、第三方脚本、网络字体、上传接口、fetch 或 XHR。`connect-src 'none'` 禁止脚本网络连接。原图只存在于当前页内存，不写入本地存储。唯一外链是用户主动打开的样片许可说明。

调参有短延迟合并；新状态会终止旧预览 Worker，并用递增版本号拒绝过期结果。图片解码也有独立版本号。导出使用点击时的参数与原图快照，导出期间仍可调整预览，下载保持点击时的状态。

## 仓库文件与测试复现

- `index.html`：完整可运行程序，约 2 MB，内嵌三张样片。
- `LICENSE`：代码的 MIT 许可证，作者德里克文。
- `SOURCES.md`：第三方样片来源与许可。
- `TESTING.md`、`tests/results-v1.json`：首次验收说明及结果。
- `tests/prepare_samples.py`：从 HTML 内嵌数据恢复测试样片，无需联网。
- `tests/verify.py`、`tests/lifecycle.py`：自动化验收及页面恢复检查。

本仓库不包含截图、导出 PNG 或独立样片副本。复现测试时，这些文件生成在本地 `samples/` 与 `evidence/` 目录，不进入版本控制。

仅运行工具无需依赖。测试需要 Python、Playwright、Pillow 与 Chromium；脚本默认 `/usr/bin/chromium`，其他系统可修改测试脚本的浏览器路径。先启动上文的本机服务，然后运行：

```sh
python3 tests/prepare_samples.py
python3 tests/verify.py
python3 tests/lifecycle.py
```
