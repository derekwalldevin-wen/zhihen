# 纸痕 · 纸压与印章工坊 v2

作者：德里克文。2026-10-09。本次发布沿用已交付并复测的 v2 候选代码；为保证字节一致，网页页脚仍保留「候选」字样。v1 可从 Git 历史查看。

## 运行

运行只需 `index.html`，约 2 MB，包含全部 CSS、JavaScript、本地 Worker 与三张许可明确的样片。无需 API、联网、登录或依赖。用支持本地 HTML 和 Blob Worker 的现代浏览器打开；系统禁止直接打开本地 HTML 时，可在本目录执行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8767/index.html`。手机应使用真正的浏览器，而非不运行 JavaScript 的文件预览器。没有 Service Worker，不承诺远程网页断网刷新；完整 HTML 可在离线环境使用。

## 四种真实工艺差异

| 工艺 | 区域与压边 | 光照与纸面 |
| --- | --- | --- |
| 细腻盲压 | 五级柔化区域，窄压边 | 克制浅影，细纹理 |
| 深凹压印 | 四级区域，内凹方向 | 加强局部内影与压边，降低体块光照 |
| 柔软棉纸浮凸 | 六级区域，更宽柔化压边 | 较柔和的大形起伏，棉纸纤维 |
| 粗纤维手工纸 | 四级区域，中等压边 | 连续不规则纤维及低频纸面起伏 |

模式不是只换纸色。所有模式可调整深浅、细节简化、光向、纸纹、纸色；「反转凹凸」将当前工艺的方向反转。默认是细腻盲压，印章关闭、无留边。

v1 直接对平滑亮度求梯度。v2 在长边约 640 的分析场中做三轮双边滤波以去掉低对比碎纹，再用连续的柔化分区形成浅高度；分别计算窄压边、较宽体块和局部遮光。目标像素逐点采样这个高度场，重新计算侧光与连续纤维，**不放大预览截图**。导出会重新从原图取样分析；字体和纹理按最终像素绘制。

这是亮度风格化，不是 AI 场景理解或真实深度。原照片阴影仍可能被当成凹凸；复杂背景、毛发、服装细节不能自动剔除。提高简化会减少杂纹，也会损失表情细节。四种模式是纸面视觉模拟，不是可直接制作实体模具的深度数据。

## 艺术印章

- 开关印章；方章、圆章、长条章。
- 最多 12 个汉字、英文字母、数字、空格或 `· . -`，超限或其他字符有明确提示，保留原输入，不静默截断。印章开启且文字无效时暂停盖印并禁用导出。
- 清空文字保留章框；关闭开关则完全不印，包括导出。
- 朱红、墨黑、靛蓝或自定义印色；大小 8%–38%，以纸面短边为基准；浓淡 0%–100%。长条章有固定宽高比例。
- 拖动结果画面里的印章，支持鼠标与触摸。也可以使用横向、纵向位置滑块；按钮「查看纸面与印章」可返回预览。
- 位置采用整张纸面的归一化坐标，自动保留 1% 安全边界；裁切比例改变时重新夹紧，避免章框出界。它不绑定照片中的某个主体。
- 以轻微不均匀墨迹与正片叠底模拟吸墨，无投影、不生成贴纸底色。字体使用系统宋体类字体，缺字和跨平台字形差异取决于设备；常用中文、英文已验证。
- 可选 6% / 10% 空白留边。原图对照也应用相同比例的留边与裁切。

## 保留的功能

JPG/PNG 导入及拖放，25 MB / 4800 万像素保护；三张内嵌样片；原比例及 3:4、1:1、4:3 居中等比裁切；双画面对照；恢复默认（保留当前照片）；1600 / 2400 / 3200 长边 PNG。

默认单图没有 UI 标识、署名、自动标题或水印。用户主动开启印章时才包含其文字。上下对比图原图在上、完整纸面和印章在下，最终高度为单张的两倍。导出使用点击时的参数快照；导出期间改动不会污染正在导出的版本。

新预览取消旧 Worker，渲染结果带版本号；图片解码有独立版本号。印章在当前纸面上独立重绘，文字和位置无需重跑照片分析。

没有照片上传、统计、外部字体、外部模型或网络脚本。`connect-src 'none'` 禁止脚本网络连接。唯一外链是用户主动点击的素材许可说明。

## 仓库文件与复现

仓库包含 HTML、README、CHANGELOG、TESTING、MIT LICENSE、SOURCES 及测试脚本和结果。截图、真实对比图和代表导出不重复上传仓库；运行测试可在本地生成。原始素材已内嵌，不重复存放。

测试需要 Python、Playwright、Pillow、NumPy 和 Chromium。脚本默认 `/usr/bin/chromium`；其他系统需调整测试脚本的浏览器路径。在本机服务运行后执行：

```sh
python3 tests/prepare_samples.py
python3 tests/verify_v2.py
```

脚本在本地生成 `samples/` 与 `evidence/`；复测请在新解压目录运行以保留既有结果。
